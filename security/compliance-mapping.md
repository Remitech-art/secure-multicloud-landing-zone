# Compliance Mapping

## Frameworks

- Map platform controls to CIS benchmarks, NIST CSF, and relevant cloud provider security best practices.
- Use documentation artifacts to capture alignment and evidence.

## Core Controls

- Identity and Access Management: enforce MFA, least privilege, and role separation.
- Data Protection: encrypt data in transit and at rest, manage keys centrally.
- Logging and Monitoring: enable audit logs, retain logs, and deploy alerting.
- Incident Response: define roles, runbooks, and response workflows.

## Cloud-Specific Mapping

- GCP: Security Command Center, Cloud Audit Logs, IAM policy analyzer.
- Azure: Azure Policy, Azure Monitor, Key Vault access logs.
- AWS: CloudTrail, Config, GuardDuty.

## Recommendations

- Build a compliance dashboard linked to the security documentation.
- Use tags and labels consistently for audit tracking.
- Validate compliance status regularly with automated controls.
